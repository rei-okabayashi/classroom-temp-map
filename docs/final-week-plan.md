- [ ] 9/9に企画者が15:05から教室に居られるか（居られない場合は集約表示オーナーが代行。手順は同じ）

### 当日の手順（15:05〜15:30）

docs/first-boot-check.md C章のとおりです。要点だけ再掲します。

1. **M5Stackの電源を切ってから**SDカードを抜きます（通電中に抜くと記録が止まります）。
2. 学校PCで `LOG.CSV` を `analysis/` フォルダへコピーします。
3. `LOG.CSV` をDiscordの #進捗報告 に添付して投稿します（分析担当への受け渡し。リポジトリには入れません）。
4. SDを戻して電源を入れ、「SD OK」を確認します。
5. TIMEコマンドを再送し、エコーバックの時刻を手元の時計と目視で照合します。
6. 投稿の本文に「回収 9/9 15:xx、行数○行、最終行の recv_time ○○」を書きます（分析担当が受け取ったファイルの新しさを確認できるように）。
