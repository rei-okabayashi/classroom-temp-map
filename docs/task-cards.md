# タスクカード（Issue）入門 — 見かた・作り方・動かし方

- 対象：チーム全員です。タスクカードを見たことも使ったこともない前提で書いています。
- タスクカード＝GitHub（書いたプログラムの変更履歴を記録・共有できるWebサービス）の「**Issue（イシュー）**」機能のことです。**やること1件を1枚のカードに書いて、チームで共有する**しくみです。ホワイトボードにふせんを貼って仕事を分けるのと同じ発想を、GitHub上でやります。

## 1. カード1枚の実物イメージ

1枚のカードの中身はこれだけです：

> **タイトル**：n2: センサーを配線する
>
> **ゴール（何ができたら完了？）**：ESP32-DevKitC-32E に SHT31 を配線し、シリアルモニタに温度と湿度が表示される
>
> **メモ・参考**：（これは記入イメージの例です。実物の初期タスク一覧は docs/tasks-initial.md にあります）困ったらDiscordで相談
>
> **見積もり**：30分
>
> **担当（Assignees）**：自分のGitHubユーザー名
>
> **ラベル**：`node`

書き方のコツは2つだけです：

- タイトルは「見ただけで何をするか分かる」短い文にします。
- ゴールは「〜が表示される」「〜が届く」のような、**できたかどうかを確認できる状態**で書きます（「〜をがんばる」型にはしません）。

ラベル＝カードの種類分けタグです。このチームでは `node`（ノード側）／`gateway`（集約側）／`docs`（文書・スライド）／`analysis`（分析）／`ops`（環境・運用）の5つを使います（意味の一覧は [docs/tasks-initial.md](tasks-initial.md) にあります）。

## 2. どこで見るか

- リポジトリ（プロジェクト一式の保管場所ページ）の上部にある「**Issues**」タブ：カードの一覧です。自分の担当分だけ見たいときは、一覧の上にある「Assignee」で自分のユーザー名を選びます。
- ※GitHubには「Projects」という、カードを「やる予定／作業中／完了」の列に並べるカンバンボード機能もありますが、**このチームでは使いません**。覚える画面を減らすためです。進み具合は「Issueが閉じたかどうか」と毎日のDiscord2行報告で十分共有できます。

## 3. 誰がいつ作るか

- **最初のカードは企画者がまとめて作ります**。[docs/tasks-initial.md](tasks-initial.md) にある初期タスク26件を、Day 0のあとにIssueとして登録します。**メンバーは最初は1枚も作らなくてOKです**（見かたと動かし方だけ分かれば十分です）。
- 作業しているうちに「これもやらないと」を見つけたら、**誰が作ってもOK**です（作り方は次の章。1分でできます）。カードにするか迷ったら、Discordで「これカードにする？」と聞けば大丈夫です。

## 4. カードの作り方（1分でできます）

1. リポジトリの「**Issues**」タブを開き、緑の「**New issue**」ボタンを押します。
2. テンプレートを選ぶ画面が出るので「**タスク**」を選びます（ゴール・メモ・見積もりの記入欄が最初から入った状態で始まります）。
3. タイトルと中身を書きます（1章の例のように。全部埋まらなくても大丈夫です。見積もりが分からなければ空欄でOKと、テンプレートにも書いてあります）。
4. 右側の「**Assignees**」で担当者を選びます（自分がやるカードなら自分を選びます）。
5. 右側の「**Labels**」で種類（`node` など）を選びます。
6. 「**Create**」（緑のボタン。「Submit new issue」と表示されることもあります）を押して完成です。カードを作ったら、Discordの2行報告のついでに「カード作った」とひとこと添えてもらえると、チームが気づけます。

## 5. ふだんの動かし方

- **月曜キックオフ**：自分の担当カードを見て、今週やる分をひとことで確認します。
- **着手したら**：特別な操作は要りません。毎日のDiscord2行報告（きょうやった／困ってる）が「いま作業中」の共有を兼ねます。
- **終わったら**：カードを閉じます（カードを開いて下の方にある「**Close issue**」ボタン）。閉じたカードは消えるわけではなく「完了の記録」として残ります。
- プログラムの変更をともなうタスクは、PR（「この変更を本体に取り込んでください」という提案）の説明欄にカード番号を `#12` のように書いておくと、どの変更がどのタスクのものか、あとから辿れます。
- カードのコメント欄は、そのタスクに関するメモや相談の置き場に使えます。日々の報告はDiscordの2行でOKなので、**あとで読み返したいことだけカードに書く**、と使い分けます。
