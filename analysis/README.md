# analysis — 運用データの分析（データ分析担当の作業場所）

1. SDカードの `LOG.CSV`（CSV＝カンマ区切りの表形式ファイルです。Excelやスプレッドシートでそのまま開けます）をこのフォルダにコピーします。
2. 次のコマンドを実行します。

```bash
python log_to_sqlite.py LOG.CSV
```

このコマンドは `LOG.CSV` を読み込み、SQLiteのデータベースファイル `onmura.db` を作ります。

- `onmura.db`（SQLite。ファイル1つで使える小さなデータベースです。訓練校で学習済み）が作られ、ノード（教室に置く測定係の小さなコンピューターです）別サマリと「時間帯×ノードの平均気温」クロス表が表示されます
- **最大差の列が「温度ムラ」そのものです** — 発表の根拠データはここから作ります
- 訓練で習ったSQLiteの実践場所です。`sqlite3 onmura.db`（作られたデータベースを開いて、自分で集計を試すためのコマンドです）で開いて自由に集計してかまいません
- `sample/LOG.CSV` は動作確認用のダミーデータです（実データが無くても試せます）

時刻未設定（clock=unset）の行とセンサーエラー行は自動で除外されます（`--include-unset` で含められます）。
