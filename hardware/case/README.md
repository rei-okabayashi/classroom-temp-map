# ノードケース（3Dプリント）

ESP32-DevKitC-32E（秋月 115673）と SHT31温湿度センサー（秋月 112125）を、
ジャンパー線4本でつないだまま収納するケースです。Bambu Lab A1 mini での印刷を前提にしています。

## 設計のいちばん大事な話 — センサーは箱に入れない

ESP32は動作中に自分が発熱します（無線送信と電源レギュレータの熱です）。
温度センサーを同じ箱に閉じ込めると、**教室の気温ではなく「箱の中の温度」を測ってしまい、
実際より1〜3℃高い値**が出ます。教室の温度ムラ（想定される差は数℃）を測るプロジェクトでは致命的です。

そこでこのケースは3パーツ構成にして、センサーだけ外に出しています。

| パーツ | 中身 | 特徴 |
|---|---|---|
| `body`（本体） | ESP32-DevKitC-32E | 基板を棚に載せ、下の空間にジャンパー線を収納。micro-USBの切り欠き、通気スリット、取付け耳つき |
| `lid`（フタ） | — | かぶせ式キャップ。裏のポストが基板を軽く押さえる。書き込み直し（BOOTボタン）のときは外す |
| `pod`（センサーポッド） | SHT31モジュール | ルーバー（通気スリット）だらけの小さな塔。本体側面のアリ溝レールに上からスライドして装着。底は全開放で、ここから空気とジャンパー線が入る |

配線（3V3・GND・SDA21・SCL22 の4本）は、本体側面の下の穴から出て、ポッドの底へ回り込みます。

## ファイル

- `node_case.scad` … 設計の元データ（OpenSCADというテキストで書ける無料CAD。寸法は全部この中の変数）
- `stl/node_case_body.stl` / `_lid.stl` / `_pod.stl` … そのままスライサーに読み込める形状データ

STLを作り直すときは [OpenSCAD](https://openscad.org/)（無料・Windows対応）を入れて：

```
openscad -D "part=\"body\"" -o stl/node_case_body.stl node_case.scad
openscad -D "part=\"lid\""  -o stl/node_case_lid.stl  node_case.scad
openscad -D "part=\"pod\""  -o stl/node_case_pod.stl  node_case.scad
```

GUIで開いて `part` の値を書き換え→F6→STLエクスポートでも同じです。

## 印刷手順（Bambu Studio / A1 mini）

1. Bambu Studio に STL を3つドラッグ＆ドロップ
2. フィラメント: **PLA**（教室内の常温用途なので十分。反りにくく一番簡単）
3. 設定: 層0.2mm / 壁3周（ウォールループ3） / インフィル15% / **サポート不要**
4. 向き: **3パーツとも、エクスポートされたそのままの向き**で印刷します
   - body … 開口部が上
   - lid … 平らな天板が下
   - pod … 開口部（底）が下
5. 目安時間: body 約2時間、lid・pod 各30〜40分。4台分でだいたい丸1〜2日（プレート単位でまとめて印刷可）

### 最初の1台はテスト印刷

いきなり4台分刷らず、まず1セット印刷して現物合わせをします。合わないときは
`node_case.scad` の先頭にある変数を調整して刷り直します：

| 症状 | 直す変数 | 方向 |
|---|---|---|
| ESP32基板が入らない／ガタガタ | `tol`（既定0.4） | 大きく／小さく |
| フタがきつい・入らない | `lid_tol`（既定0.2） | 0.3〜0.4に |
| ポッドがレールに入らない・すぐ落ちる | `dove_tol`（既定0.3） | 大きく／小さく |
| SHT31基板が溝に入らない | `sht_w`・`sht_t` | **ノギスで実測した値**に |

特に `sht_w`（SHT31基板の幅=既定14.0mm）は**印刷前に現物を実測**してください。
ESP32側（54.4×27.9mm）は公式寸法なのでそのままで大丈夫なはずです。

## 組み立て

1. **SHT31のピンヘッダは基板の裏側（部品がない面）から下向きに**はんだ付けする
   （ポッドに入れたとき、ピンが底の開口から下に出る向きです）
2. ジャンパー線（メスメス4本）をESP32のピン（3V3・GND・21・22）に挿し、
   反対側をSHT31（+V・GND・SDA・SCL）に挿す。**先にPCにつないで動作確認**
   （[docs/first-boot-check.md](../../docs/first-boot-check.md) のA章）してからケースに入れる
3. ESP32を本体に入れる: 基板を斜めにしてUSBコネクタを切り欠きに合わせ、
   両端の棚に載せる。ジャンパー線は基板の下の空間にたるませ、側面下の穴から4本出す
4. フタをかぶせる（USB切り欠きがある側を合わせる。裏のポストが基板の両端を押さえます）
5. SHT31をポッドへ: 底の開口から差し込み、左右の溝に基板の縁を滑らせて上まで入れる。
   ジャンパー線がストッパー代わりになるので接着は不要
6. ポッドを本体側面のレールに上からスライドして装着
7. 設置: 取付け耳（穴φ4）にネジ・結束バンド・画鋲ひも等。平置きなら両面テープでも可

## 完成後の検証（おすすめ）

ケースの影響を数字で確かめておくと発表のネタになります：

- 同じ場所で「ケースあり」と「センサーむき出し」のノードを並べて30分放置し、温度差を記録する
- 差が0.5℃以内ならケースの影響は無視できる。大きければポッドのルーバーを増やす／ポッドを本体からさらに離す（アリ溝に挿さずケーブルの届く範囲でぶら下げる）

うまくいかないときの逃げ道: ポッドをレールに挿さず、ジャンパー線の先にぶら下げるだけでも機能します（熱分離はむしろ良くなります）。

## 設置時の注意

- 直射日光の当たる場所は避ける（日射でセンサーが数℃高く出ます。窓際に置くなら日陰側に）
- エアコンの吹き出し直下も避ける（気流の温度を測ってしまいます）
- ESP32のアンテナ（基板の端の模様部分）の周りに金属（スチール棚の面など）を密着させない。
  ケースのPLA樹脂自体は電波をほぼ通すので問題ありません
