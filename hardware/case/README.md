# ノードケース（3Dプリント）

ESP32-DevKitC-32E（秋月 115673）と SHT31温湿度センサー（秋月 112125）を収める、
教室常設用のケースです。Bambu Lab A1 mini での印刷を前提にしています。
ここにあるのは2026年8月30日時点の版（v3）で、4台ともこのケースに入れて9月1日から教室に設置しました。

## 設計のいちばん大事な話 — センサーとESP32を縦に離す

ESP32は動作中に自分が発熱します（無線送信と電源レギュレータの熱です）。
温度センサーを同じ空間に閉じ込めると、**教室の気温ではなく「箱の中の温度」を測ってしまい、
実際より高い値**が出ます。教室の温度ムラ（実測で数℃）を測るプロジェクトでは致命的です。

そこでこのケースは、**下からセンサー室 → 空気の断絶帯 → ESP32室** の縦積みにしています。

```
        ┌──────────┐
  +48.8 │   lid    │  フタ。ESP32を上から押さえ、CPU直上に排熱の煙突とハニカム孔
        ├──────────┤
  +24.5 │   box    │  ESP32室。基板を棚に載せる。USB窓・配線穴・排気スリット
        ├──────────┤
        │  = 空気 = │  断絶帯 5.0mm（ここで熱がセンサーへ伝わりにくくなる）
        │          │
      0 │  shell   │  外殻。最下部がセンサークレードル（SHT31を上から落とし込む）
        └──────────┘   背面に磁石ポケット2個。底面の前バンドにノードIDを刻印
```

全高58.5mm、設置面は 60.3 × 33.5mm。**背面（机側）はshellからlidまで1枚の平面**なので、
磁石で壁やスチール面にぴったり付きます。

## パーツ構成

| ファイル | 中身 |
|---|---|
| `stl/node_case_v3_shell_n1.stl` 〜 `_n4.stl` | 外殻＋センサークレードル。**n1〜n4で違うのは底面の刻印だけ**です（設置後にどの子機か見分けるため） |
| `stl/node_case_v3_box.stl` | ESP32室。4台とも共通 |
| `stl/node_case_v3_lid.stl` | フタ。4台とも共通 |
| `node_case_v3.py` | 設計の元データ（後述） |

1台分 ＝ shell 1個 ＋ box 1個 ＋ lid 1個。4台なら shell を n1〜n4 で1個ずつ、box と lid を4個ずつ。

## 部品以外に必要なもの

- **ネオジム磁石 φ13 × 厚2.4mm × 2個／台**（ダイソーの13mmタイプを実測した寸法でポケットを作っています）。
  shell背面のポケットに押し込みます。2個の縁を25.6mm離してあるのは、磁石どうしが引き寄せ合って
  設置しづらくなるのを避けるためです。SHT31への磁気の影響は調べたうえで無しと判断しています。
- ジャンパー線（メスメス4本。3V3・GND・SDA21・SCL22）

## 印刷

1. Bambu Studio に STL をドラッグ＆ドロップ
2. フィラメント: **PLA**。
   ただし **PLA Matte は層間の強度が PLA Basic の43%しかありません**（メーカーTDSの実測値）。
   スナップのツメなど細い部分が折れやすいので、Matteを使うなら扱いを丁寧に
3. 向き: **3部品ともエクスポートされたそのままの向き**で置けば、サポートは要りません
4. 最初は1台分だけ刷って実物で確かめてから、残り3台を刷ってください

### 寸法を変えたいとき

`node_case_v3.py` の先頭にパラメータがまとまっています（壁厚 `WALL`、外形 `FOOT_X`/`FOOT_Y`、
空気断絶帯 `GAP`、磁石 `MAGNET_D`/`MAGNET_T`、USB窓 `USB_SLOT_W` など）。
値を変えて実行すればSTLが出し直されます。

このファイルは [build123d](https://github.com/gumyr/build123d)（Pythonで形状を書くCAD）で動きます。

```
pip install build123d
python node_case_v3.py
```

実行すると `node_case_v3_box.stl` / `_lid.stl` / `_shell_n1`〜`_n4.stl` が同じフォルダに出力されます。

## 組み立て

1. **SHT31のピンヘッダは基板の裏側（部品がない面）から下向きに**はんだ付けします
2. ジャンパー線4本でESP32（3V3・GND・21・22）とSHT31（+V・GND・SDA・SCL）をつなぎ、
   **先にPCにつないで動作確認**（[docs/first-boot-check.md](../../docs/first-boot-check.md) のA章）してからケースに入れます
3. **SHT31をshellのクレードルへ**：**タブ（センサー素子が載っている出っぱり）を先に差し込んでから、
   後端を落とす**順番で入れます。先端のツメが基板の浮き上がりを押さえます
4. **ESP32をboxへ**：USBコネクタを右壁（X+）の窓に合わせて、基板を棚に載せます。
   ジャンパー線は基板の下の空間を通し、配線穴から下（shell側）へ回します
5. **boxをshellに載せる**：パラペット（shell上部の立ち上がり）の内側に差し込むと、
   ビードが受け溝にはまってカチッと止まります
6. **lidをかぶせる**：短辺（X±）のスカート脚がboxの壁をつかみます。書き込み直し（BOOTボタン）のときは外します
7. **磁石を2個**、shell背面のポケットに押し込んで設置

## この設計に至るまで（初回印刷でわかったこと）

8月30日の午前にフル1セットを試し刷りし、その実物を見て午後に直しました。
直した内容は `node_case_v3.py` の冒頭コメントに全部残してあります。主なものは：

| 見つかった問題 | 直し方 |
|---|---|
| センサー基板が浮き上がる | 先端にツメ（トンネル状の押さえ）を新設。両側のナブを太くする案は、通過隙間12.7mm＜基板幅14.0mmで**挿入できなくなる**ため不採用 |
| boxとshellが固定されない | 押し込んで嵌るスナップを新設（ギャップ0.5mmを跨いで0.30mm食い込む2段ビード） |
| ESP32の熱がこもる | lidの押さえパッドを煙突にしてCPU直上を貫通、プレートにハニカム孔、box壁の排気スリットを下へ延長 |
| 磁石どうしが引き寄せ合って設置できない | 2個を離して独立したポケットに（縁間25.6mm） |
| ESP32の赤LEDが眩しい | ハニカム孔をCPU側（X-）だけに限定し、LED側は無孔の目隠しに |
| 横の出っぱりが邪魔で壁に付き切らない | 長辺（Y±）を本体と面一化。lidのY側スカートを廃止し、係合を短辺（X±）へ移設 |
| 外壁と内壁が細くて不安定 | 薄壁2枚が非接合で並んでいた箇所を、段付きキャビティで一体の2.5〜3.7mm壁に統合 |

その前段では、嵌合部だけを切り出したテスト用の小片（クーポン）を刷って、
スナップの食い込みと、この設定で形が出る最小の寸法を確かめています。

## 設置時の注意

- 直射日光の当たる場所は避ける（日射でセンサーが数℃高く出ます。窓際なら日陰側に）
- エアコンの吹き出し直下も避ける（気流の温度を測ってしまいます）
- ESP32のアンテナ（基板端の模様部分）に金属を密着させない。ケースのPLA樹脂自体は電波をほぼ通すので問題ありません

## ケースの影響について

このケースが測定値を持ち上げていないか、**ケースあり／なしを並べて比べる測定はしていません**。
4台とも同じケースに入っているので、持ち上がりがあれば4台に同じだけ乗り、
このプロジェクトが見たい「地点どうしの差」には影響しない、という整理です。
絶対値の底上げがあるかどうかは未測定です（[docs/presentation-outline.md](../../docs/presentation-outline.md) の想定問答3）。
