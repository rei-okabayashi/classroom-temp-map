# firmware/nodes/ — 各自のノードのコード置き場

このフォルダには、**自分が担当するノードのコード**を置きます。`n1/`〜`n4/` の各フォルダが、そのまま担当者1人分です。
どの番号が誰の担当かは、リポジトリのトップの [README.md](../../README.md) の構成図と役割分担表を見てください。

## 置くファイルは2つだけです

`firmware/node-template/` の中身をコピーして、自分の番号に合わせた名前で置きます。

- `nX.ino` … `node-template.ino` をコピーして名前を変えたもの
- `config.h` … そのままコピーして、下の2か所だけ書き換えたもの

**フォルダ名と `.ino` のファイル名は必ずそろえてください**（`n2/` なら `n2.ino`）。
名前が違うと Arduino IDE でスケッチ（プログラムのひとまとまり）を開けません。

## 書き換えるのは2か所だけです

`config.h` の中の次の2つだけを変えます。ほかは変えません。

- `NODE_ID` … 自分の番号（`"n2"` のように書きます）
- `GATEWAY_MAC` … 集約M5StackのMACアドレス（機器1台ごとに付いている固有の番号です）

## GitHubに上げるときの注意

**`GATEWAY_MAC` は、雛形の `{0x00, 0x00, 0x00, 0x00, 0x00, 0x00}` に戻してからコミットしてください。**
教室に置いてある機材のアドレスを、誰でも見られる場所に残さないためです。

そのため、**ここに置いてあるコードは、そのままでは動きません**。
実機に書き込むときは、各自が自分の手元でMACアドレスを本当の値に直してから書き込みます。
MACアドレスは、gateway（M5Stack）を起動したときに画面とシリアルモニタに `MAC: 24:0A:C4:12:34:56` の形で出ます。
`config.h` に書くときは、①コロン `:` をカンマ `,` に変える ②2文字ずつの前に `0x` を付ける ③全体を `{ }` で囲む、の3つだけです。

```
【画面に出る表示】  MAC: 24:0A:C4:12:34:56
【config.h に書く形】static const uint8_t GATEWAY_MAC[6] = {0x24, 0x0A, 0xC4, 0x12, 0x34, 0x56};
```

書けたら数えてください。**`0x` が6個、カンマが5個**あれば正しい形です（上の値は書き方の例です）。

## `.gitkeep` というファイルについて

各フォルダに入っている `.gitkeep` は、**中身が空のフォルダをGitで扱えるようにするためだけ**に置いてある、何も書かれていないファイルです。
Gitは「空のフォルダ」を記録できないので、置き場所を先に作っておくために使っています。

自分のコードを置いたあとは、消してもかまいません（残っていても害はありません）。
